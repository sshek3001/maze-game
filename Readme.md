## THIS IS A MAZE SIMULATOR

### How it works
- **Generation:** randomized depth-first search (the "recursive backtracker"
  algorithm) — carves passages one step at a time from a stack, so you watch
  the maze grow organically instead of appearing instantly.
- **Solving:** breadth-first search (BFS) from the top-left cell to the
  bottom-right cell, animated frontier-by-frontier (shown in blue), then the
  shortest path is traced and highlighted in yellow.
